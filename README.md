# Slai Agent Benchmark Result Archive

This repository is a sanitized benchmark result archive for Slai Agent Runtime.

It preserves the submission/evidence artifacts that were prepared for official benchmark channels, plus a newer public Harbor job set that is awaiting/subject to official leaderboard process clarification.

No API keys, private prompts, account tokens, dependency caches, VM images, or full runtime dumps are intentionally included.

## Contents

- `benchmarks/terminal-bench/TB2.1/official-submission/`  
  Terminal-Bench 2.1 official submission package: 89 accepted K=5 tasks, 445/445 trials, clean 5/5, with public Harbor job links and the leaderboard `source_jobs` JSON.

- `benchmarks/terminal-bench/TB4-0/`  
  Newer Terminal-Bench run archive from local workspace `D:\terminal_bench_3_slai`. The local workspace files call this line TB3 / `terminal-bench/terminal-bench@3.0.0`; this archive keeps the owner-facing label `TB4-0` pending official naming/process clarification. Current accepted manifest: 60 accepted K=5 tasks, 300/300 trials, all reward 1.0, with 60 public Harbor job links.

## Status wording

These artifacts are archived as independently reproducible Slai Agent Runtime benchmark evidence. Official leaderboard display or inclusion is a separate process controlled by benchmark maintainers.
